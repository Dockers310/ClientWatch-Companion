# ClientWatch Companion 1.0.6

Клиентский Fabric-мод для Minecraft 26.2, companion к серверному ClientWatch.

## Что делает

После запроса от сервера ClientWatch мод только собирает список загруженных Fabric-модов клиента и для доступных локальных JAR вычисляет SHA-512. Список передаётся только подключённому серверу ClientWatch через vanilla Custom Payload.

Мод полностью пассивный: у него нет команд, меню, кнопок, настроек и действий по инициативе игрока. Он не начинает проверку сам и ничего не отправляет без серверного запроса. Единственное действие — ответить серверу ClientWatch на специально отправленный сервером запрос.

## Важно

Companion повышает полноту проверки, но не даёт абсолютной гарантии честности клиента: модифицированный клиент способен отправить изменённые данные. SHA-512 подтверждает байты файла, которые клиент действительно прислал серверу, но не доказывает отсутствие лжи в самом отчёте.

## Сборка

Требуется Java 25 и сеть для получения Minecraft/Fabric/Gradle зависимостей.

`./gradlew build`


## Версия 1.0.5

Пассивный companion без команд и GUI. Серверный запрос получает список модов, версии, SHA-512, SHA-1, версию Minecraft, Fabric Loader и доступное определение лаунчера.
\n\nДля совместимости с Paper/Bukkit сервером отправка ответа выполняется через обычный vanilla `ServerboundCustomPayloadPacket`, без проверки Fabric API `ClientPlayNetworking.canSend`.\n
